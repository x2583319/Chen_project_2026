# Project Structure

This repository is organized as a BrainHack School 2026 project repository.

## Main directories

- `bhs_modules/`: completed BrainHack School module work.
- `data/raw/`: raw or original input data. Large data files are not committed.
- `data/processed/`: processed/intermediate data outputs. Large files are not committed.
- `docs/`: project notes and documentation.
- `figures/`: generated figures.
- `notebooks/`: exploratory notebooks.
- `reports/`: written reports or module summaries.
- `src/`: reusable project code.
- `tests/`: lightweight tests or validation scripts.

Empty directories are tracked with `.gitkeep` files.
